# 🏦 Sistema de Caixa Eletrônico em Java

Um sistema de terminal simples desenvolvido em Java que simula o funcionamento básico de um caixa eletrônico. Este projeto foi criado para praticar conceitos essenciais de lógica de programação e estruturas de controle.

## 🚀 Funcionalidades

- *Consulta de Saldo:* Permite visualizar a quantia atual disponível na conta.
- *Saque Simples:* Realiza retiradas de dinheiro validando se há saldo suficiente para concluir a operação.
- *Interface via Terminal:* Menu interativo estruturado com switch-case e laço de repetição do-while.

## 🛠️ Tecnologias Utilizadas

- *Java* (Versão SDK compatível)
- *Scanner* (Para capturar entradas do usuário no terminal)

## 💻 Como Rodar o Projeto

1. Certifique-se de ter o Java instalado em sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o projeto na sua IDE favorita (IntelliJ, VS Code, Eclipse, etc.).
4. Execute o arquivo Main.java localizado dentro da pasta src/.
5. Interaja com o sistema através do terminal de comandos digitando os números do menu.
